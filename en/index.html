Programas is a programming course for iPhone and iPad, in English and Spanish, in three languages: Python, JavaScript and Swift. It has 44 months, 311 lessons and 260 programs that run in front of you, line by line, with the memory and the console in view. The first month of every language is free; all three full courses unlock with a single payment.

Questions

I have never programmed. Is it for me?

Yes. Every course starts with the very first instruction and each month builds on the last. Ten minutes a day is enough.

Which language should I choose?

Python is the easiest to start with. JavaScript is the language of the web. Swift is the language of iPhone, iPad and Mac apps. You can switch whenever you like and your progress in each one is kept.

Do I need a computer?

No. The programs run inside the app. In the sandbox you can write your own and watch them run step by step.

Does the code work the same outside the app?

Yes: the course's programs give the same output in Python, in a web browser or with Swift in Xcode. The app uses its own interpreter so it can show you every step, and it covers what the course teaches, not every library of each language.

I changed iPhone and cannot see my purchase

Go to Progress › Restore purchase, with the same Apple Account you bought it with. The purchase works with Family Sharing.

Does it work offline?

Yes. The whole course is inside the app. You only need a connection to buy or restore.
